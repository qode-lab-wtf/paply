# Paply unter Windows installieren

Kurzanleitung zum Weitergeben (z. B. an Freunde). Dauer: ca. 5 Minuten.

## 1. Herunterladen

Auf <https://github.com/qode-lab-wtf/paply/releases/latest> die Datei **`paply-Setup-<Version>.exe`** laden.

## 2. Installieren

Doppelklick auf die EXE. Windows zeigt vermutlich **„Der Computer wurde durch Windows geschützt“**
(die App ist nicht kostenpflichtig signiert):
→ **Weitere Informationen** → **Trotzdem ausführen**. Danach den Installer durchklicken.

## 3. Ersteinrichtung

Paply startet und führt durch fünf kurze Schritte:

1. **Groq-Schlüssel (kostenlos):** Auf „Kostenlosen Schlüssel holen“ klicken → bei Groq anmelden →
   *Create API Key* → Schlüssel kopieren → in Paply einfügen → **Prüfen**.
2. **Mikrofon:** „Mikrofon prüfen & freigeben“. Falls blockiert: Windows-Einstellungen →
   Datenschutz & Sicherheit → Mikrofon → Desktop-Apps den Zugriff erlauben.
3. **Tastenkürzel:** Standard ist **Strg + Alt + K**.
   - Kurz tippen = Aufnahme an, nochmal tippen = aus.
   - Gedrückt halten = sprechen, loslassen = fertig.
   Der Text erscheint dort, wo der Cursor stand.

## 4. Wo ist Paply?

Paply sitzt unten rechts im **Infobereich der Taskleiste** (ggf. hinter dem Pfeil **^**). Rechtsklick
auf das grüne „p“ → Einstellungen, Verlauf, Beenden. Tipp: Das Symbol per Drag & Drop neben die Uhr
ziehen, dann ist es immer sichtbar.

## Wenn etwas nicht klappt

- **Nichts wird eingefügt:** Der Text liegt trotzdem in der Zwischenablage → **Strg + V**.
- **Letzte Aufnahme wiederholen:** **Strg + Alt + Shift + R**.
- **Fehler „Schlüssel ungültig“:** Einstellungen → Groq-Schlüssel neu einfügen.
- Updates kommen automatisch über die App.
