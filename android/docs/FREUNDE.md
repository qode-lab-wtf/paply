# Paply Android · 0.2.0

1. Öffne die APK im Anhang. Android fragt, ob du diese Quelle erlaubst – bitte erlauben. Dann installieren.
2. Play Protect eingeschaltet lassen. Bei einer Warnung oder Blockierung erst Allan einen Screenshot schicken.
3. Öffne Paply. Auf der Karte „Einrichten“ jeweils den grünen Knopf tippen, bis alles abgehakt ist.
4. Groq-Schlüssel: „Eintragen“ → „Kostenlosen Schlüssel holen“ → bei Groq anmelden → „Create API Key“ → kopieren → zurück zu Paply → „Einsetzen“. Das ist ein kostenloser Zugang zur Spracherkennung. Den Schlüssel geheim halten und nirgends posten.
5. Paply-Knopf einschalten (Schritt „Paply-Knopf“):
   - Ab Android 13 zuerst: App-Info → ⋮ (oben rechts) → „Eingeschränkte Einstellungen zulassen“.
   - Dann unter Bedienungshilfen „Paply“ einschalten. Die Android-Warnung ist normal. Paply erkennt damit nur, wo du gerade schreibst, und speichert nichts davon.
6. So diktierst du: In ein Textfeld tippen → über der Tastatur erscheint das kleine Paply-Symbol → antippen → sprechen → nochmal antippen → der Text steht im Feld. Deine normale Tastatur bleibt die ganze Zeit.
7. Gedanken festhalten: Schnelleinstellungen herunterwischen → Kachel „Paply-Gedanke“ → sprechen → „Fertig“. Paply ordnet Titel, Thema und Aufgaben selbst.
8. Datenschutz: Ton und Text gehen nur an Groq. Der Text bleibt auf deinem Handy, der Ton nur bis zur Umschrift (bei Fehlern höchstens 30 Tage). Allan bekommt keine Inhalte.

Alternative zum Paply-Knopf: die Paply-Tastatur (Tastatur-Symbol unten → „Paply“). Klappt das Einsetzen in einer App einmal nicht, liegt der Text in der Zwischenablage – Feld lange drücken → „Einfügen“.
